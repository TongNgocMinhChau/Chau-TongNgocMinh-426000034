Góc học tập & Thử nghiệm CSS

Hover vào các thẻ bên dưới để xem bí quyết thực hiện hiệu ứng CSS!

CSS 3D Transform

Hiệu ứng Lật thẻ 3D (Card Flip)

Hover vào đây để xem cách làm

Cách tạo Card Flip 3D

1. Dùng perspective: 1000px ở thẻ cha để tạo chiều sâu 3D.
2. Thẻ inner có transform-style: preserve-3d.
3. Khi hover: xoay rotateY(180deg).
4. Mặt sau ẩn đi nhờ backface-visibility: hidden.

Pure CSS Keyframes

Hiệu ứng Máy đánh chữ (Typing)

Hover vào đây để xem cách làm

Cách tạo Typing Effect

1. Set overflow: hidden và white-space: nowrap.
2. Dùng @keyframes thay đổi chiều rộng từ width: 0 lên 100%.
3. Kết hợp steps(...) để chữ xuất hiện theo từng ký tự.
4. Tạo viền phải border-right nhấp nháy làm con trỏ.

CSS Background

Hiệu ứng Parallax cuộn trang

Hover vào đây để xem cách làm

Cách tạo Parallax CSS

1. Đặt background-image cho Section.
2. Sử dụng thuộc tính background-attachment: fixed.
3. Căn chỉnh background-size: cover và background-position: center để hiển thị tốt trên mọi thiết bị.
